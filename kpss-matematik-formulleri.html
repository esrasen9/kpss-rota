Temel Kavramlar

  • Ardışık sayıların toplamı1 + 2 + … + n = n(n + 1) / 2
  • Ardışık çift sayıların toplamı2 + 4 + … + 2n = n(n + 1)
  • Ardışık tek sayıların toplamı1 + 3 + … + (2n − 1) = n²
  • Terim sayısı(son terim − ilk terim) / artış miktarı + 1
  • Aritmetik dizi toplamı(ilk terim + son terim) × terim sayısı / 2

Sayı Basamakları

  • İki basamaklı sayıab = 10a + b
  • Üç basamaklı sayıabc = 100a + 10b + c
  • Yer değiştirme farkıab − ba = 9(a − b)
  • Yer değiştirme toplamıab + ba = 11(a + b)

Bölme ve Bölünebilme

  • BölmeBölünen = Bölen × Bölüm + Kalan Kalan, bölenden küçüktür.
  • 3 ve 9 ile bölünebilmeRakamlar toplamı 3’e (9’a) bölünmeli
  • 4 ile bölünebilmeSon iki basamak 4’e bölünmeli
  • 8 ile bölünebilmeSon üç basamak 8’e bölünmeli
  • 11 ile bölünebilmeSağdan +, −, + … işaretli rakam toplamı 11’in katı olmalı

EBOB - EKOK

  • İki sayının EBOB ve EKOK’ua × b = EBOB(a, b) × EKOK(a, b)
  • Ne zaman EKOK?“En az, birlikte, yeniden, aynı anda” Ortak kat aranıyorsa EKOK.
  • Ne zaman EBOB?“En büyük, eşit parçalara bölme, en az sayıda” Ortak bölen aranıyorsa EBOB.

Rasyonel ve Ondalık Sayılar

  • Devirli ondalık sayıyı kesre çevirme(sayının tamamı − devretmeyen kısım) / (devreden kadar 9, devretmeyen kadar 0) Örn. 0,1̅2̅ → (12 − 0) / 99
  • Kesirlerde toplamaa/b + c/d = (ad + bc) / bd
  • Kesirlerde bölme(a/b) ÷ (c/d) = (a/b) × (d/c)

Basit Eşitsizlikler

  • Negatifle çarpmaa < b ve c < 0 ise ac > bc Negatif sayıyla çarpıp bölünce yön değişir.
  • Aynı yönlü toplamaa < b ve c < d ise a + c < b + d Eşitsizlikler taraf tarafa çıkarılmaz.
  • 0 < a < 1 isea² < a < √a 1’den küçük pozitif sayının karesi küçülür.

Mutlak Değer

  • Tanım|x| = x (x ≥ 0), |x| = −x (x < 0)
  • Denklem|x − a| = b (b ≥ 0) ⇒ x = a + b veya x = a − b
  • Küçüktür|x| < a ⇒ −a < x < a
  • Büyüktür|x| > a ⇒ x > a veya x < −a

Üslü Sayılar

  • Çarpmaaᵐ × aⁿ = aᵐ⁺ⁿ
  • Bölmeaᵐ / aⁿ = aᵐ⁻ⁿ
  • Üssün üssü(aᵐ)ⁿ = aᵐⁿ
  • Sıfır ve negatif üsa⁰ = 1 (a ≠ 0), a⁻ⁿ = 1 / aⁿ
  • Negatif taban(−a)ⁿ: n çiftse pozitif, tekse negatif −2⁴ = −16 ama (−2)⁴ = 16

Köklü Sayılar

  • Çarpma√a × √b = √(ab)
  • Kök dışına çıkarma√(a²b) = a√b (a ≥ 0) Örn. √72 = 6√2
  • Kesirli üsⁿ√(aᵐ) = aᵐᐟⁿ
  • Paydayı rasyonel yapma1 / (√a − √b) = (√a + √b) / (a − b) Eşleniğiyle çarp.
  • Kare kök√(a²) = |a|

Çarpanlara Ayırma

  • İki kare farkıa² − b² = (a − b)(a + b)
  • Tam kare (toplam)(a + b)² = a² + 2ab + b²
  • Tam kare (fark)(a − b)² = a² − 2ab + b²
  • İki küp farkıa³ − b³ = (a − b)(a² + ab + b²)
  • İki küp toplamıa³ + b³ = (a + b)(a² − ab + b²)

Oran - Orantı

  • Doğru orantıa / b = k (biri artarken diğeri de artar)
  • Ters orantıa × b = k (biri artarken diğeri azalır)
  • Orantı özelliğia/b = c/d ⇒ ad = bc

Yaş Problemleri

  • Yaş farkıİki kişinin yaş farkı hiç değişmez
  • Yaş toplamın kişinin yaşları toplamı t yıl sonra n × t artar

Yüzde, Kâr - Zarar Problemleri

  • Yüzdea’nın %x’i = a × x / 100
  • KârSatış fiyatı = Maliyet × (100 + kâr %) / 100 Kâr ve zarar maliyet üzerinden hesaplanır.
  • ZararSatış fiyatı = Maliyet × (100 − zarar %) / 100
  • Art arda iki değişimSonuç = a × (1 ± x/100) × (1 ± y/100) %20 zam + %20 indirim = %4 kayıp

Karışım Problemleri

  • Saf maddeSaf madde = Karışım × oran
  • KarıştırmaYeni oran = (m₁ × o₁ + m₂ × o₂) / (m₁ + m₂)
  • Su ekleme / buharlaştırmaSaf madde miktarı değişmez, sadece toplam değişir

Hız Problemleri

  • Temel bağıntıYol = Hız × Zaman
  • Karşılıklı hareketKarşılaşma süresi = Yol / (V₁ + V₂)
  • Aynı yönde hareketYetişme süresi = Aradaki mesafe / (V₁ − V₂)
  • Ortalama hızToplam yol / Toplam zaman Eşit yolları farklı hızla gidince: 2V₁V₂ / (V₁ + V₂)
  • AkıntıAkıntı yönünde V + a, ters yönde V − a

İşçi ve Havuz Problemleri

  • Birim zamandaki işİşi t saatte bitiren 1 saatte 1/t kadar yapar
  • Birlikte çalışma1/t₁ + 1/t₂ = 1/t (birlikte bitirme süresi t)
  • HavuzDolduran musluk +1/t, boşaltan musluk −1/t

Kümeler

  • Alt küme sayısın elemanlı kümenin 2ⁿ alt kümesi vardır Öz alt küme sayısı 2ⁿ − 1
  • Birleşims(A ∪ B) = s(A) + s(B) − s(A ∩ B)
  • Farks(A − B) = s(A) − s(A ∩ B)

Fonksiyonlar

  • Bileşke(f ∘ g)(x) = f(g(x))
  • Ters fonksiyonf(a) = b ⇔ f⁻¹(b) = a
  • Doğrusal fonksiyonun tersif(x) = ax + b ⇒ f⁻¹(x) = (x − b) / a

İşlem ve Modüler Aritmetik

  • Moda ≡ b (mod m) ⇔ a ile b’nin m’ye bölümünden kalanlar eşit
  • Haftanın günlerin gün sonrası için n’nin 7’ye bölümünden kalana bak

Permütasyon, Kombinasyon, Olasılık

  • Faktöriyeln! = 1 × 2 × … × n, 0! = 1
  • Permütasyon (sıralama)P(n, r) = n! / (n − r)!
  • Kombinasyon (seçme)C(n, r) = n! / (r! (n − r)!)
  • Tekrarlı permütasyonn! / (a! b! …) Örn. ANANAS: 6! / (3! 2!) = 60
  • Dairesel sıralama(n − 1)!
  • OlasılıkP(A) = istenen durum / tüm durumlar 0 ≤ P(A) ≤ 1

Doğruda ve Üçgende Açılar

  • Üçgenin iç açılarıİç açılar toplamı = 180°
  • Dış açıBir dış açı, kendisine komşu olmayan iki iç açının toplamıdır
  • Tümler / bütünlerTümler açılar toplamı 90°, bütünler açılar 180°

Üçgenler

  • AlanA = taban × yükseklik / 2
  • Pisagora² + b² = c² (c hipotenüs) Sık üçlüler: 3-4-5, 5-12-13, 8-15-17
  • Eşkenar üçgen alanıA = a²√3 / 4
  • Üçgen eşitsizliği|b − c| < a < b + c
  • İki kenar ve aradaki açıA = (1/2) × b × c × sin A

Çokgenler ve Dörtgenler

  • Çokgen iç açılarıİç açılar toplamı = (n − 2) × 180°
  • Dış açılarDış açılar toplamı = 360°
  • Köşegen sayısın(n − 3) / 2
  • DikdörtgenAlan = a × b, Çevre = 2(a + b)
  • Kare köşegeniKöşegen = a√2
  • YamukAlan = (alt taban + üst taban) × h / 2
  • Eşkenar dörtgenAlan = (e × f) / 2 (köşegenlerin çarpımının yarısı)

Çember ve Daire

  • Çember çevresiÇ = 2πr
  • Daire alanıA = πr²
  • Daire dilimi alanıA = πr² × α / 360°
  • Yay uzunluğuL = 2πr × α / 360°
  • Çevre açıÇevre açı, gördüğü yayın ölçüsünün yarısıdır Çapı gören çevre açı 90°.

Analitik Geometri

  • İki nokta arası uzaklık|AB| = √((x₂ − x₁)² + (y₂ − y₁)²)
  • Orta nokta((x₁ + x₂) / 2, (y₁ + y₂) / 2)
  • Eğimm = (y₂ − y₁) / (x₂ − x₁)
  • Doğru denklemiy − y₁ = m(x − x₁)
  • Paralel / dik doğrularParalel: m₁ = m₂, Dik: m₁ × m₂ = −1

Katı Cisimler

  • KüpHacim = a³, Yüzey alanı = 6a²
  • Dikdörtgenler prizmasıHacim = a × b × c, Alan = 2(ab + ac + bc)
  • SilindirHacim = πr²h, Yanal alan = 2πrh
  • KoniHacim = πr²h / 3
  • KüreHacim = 4πr³ / 3, Yüzey alanı = 4πr²
  • PiramitHacim = Taban alanı × h / 3

Sık sorulanlar

KPSS matematikte formül ezberlemek gerekir mi?

Temel formülleri (özdeşlikler, üslü-köklü sayı kuralları, yüzde ve hız bağıntıları, alan-hacim formülleri) bilmek soruları hızlandırır. Ezberden çok, her formülü birkaç soruda kullanarak öğrenmek kalıcıdır.

KPSS’de geometriden kaç soru çıkar?

Geometri soruları Matematik testinin (30 soru) içindedir; açılar, üçgenler, dörtgenler, çember, analitik geometri ve katı cisimlerden gelir.

Bu formüller uygulamada da var mı?

Evet. KPSS Rota’da 107 formülün tamamı ücretsizdir; Soru Çöz sekmesinden ve ilgili konu ekranından açılır.

KPSS’ye bugün başla

80 konuluk yol haritası, 1200 çözümlü soru ve tam deneme cebinde. Hesap gerekmez.
