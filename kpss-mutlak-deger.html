KPSS Mutlak Değer konusunda neler sorulur?

Mutlak değer; bir sayının sıfıra uzaklığı, mutlak değerli ifadelerin açılımı, denklem ve eşitsizlikler sorularını kapsar.

Bilmen gereken temel bilgiler

  • Mutlak değerin tanımı?|x| = x (x ≥ 0 ise), |x| = −x (x < 0 ise). Sonuç hiçbir zaman negatif olmaz.
  • |x| < a (a > 0) eşitsizliğinin çözümü?−a < x < a
  • |x| > a (a > 0) eşitsizliğinin çözümü?x > a veya x < −a

KPSS Mutlak Değer formülleri

  • Tanım|x| = x (x ≥ 0), |x| = −x (x < 0)
  • Denklem|x − a| = b (b ≥ 0) ⇒ x = a + b veya x = a − b
  • Küçüktür|x| < a ⇒ −a < x < a
  • Büyüktür|x| > a ⇒ x > a veya x < −a

Tüm formüller: KPSS matematik ve geometri formülleri

Mutlak Değer nasıl çalışılır?

  • Mutlak değerin içi negatifse ifade işaret değiştirerek dışarı çıkar.
  • |x − a| = b denkleminde x − a = b ve x − a = −b durumlarını ayrı çöz.
  • |x| < a ise −a < x < a; |x| > a ise x > a ya da x < −a.

KPSS Rota’da Mutlak Değer konusundan 15 çözümlü soru ve 4 bilgi kartı var. Yanlış yaptığın sorular akıllı tekrar ile 1, 3, 7 ve 21 gün sonra yeniden karşına çıkar.

KPSS Mutlak Değer çözümlü sorular

Cevabı ve çözümü görmek için soruya dokun.

1. |x − 3| = 5 denklemini sağlayan x değerlerinin toplamı kaçtır?
  1. 2
  2. 4
  3. 6
  4. 8
  5. 10

Cevap: C) 6
x − 3 = 5 → x = 8 ya da x − 3 = −5 → x = −2. Toplam 8 + (−2) = 6.

2. |−7| − |3 − 8| işleminin sonucu kaçtır?
  1. −12
  2. −2
  3. 2
  4. 4
  5. 12

Cevap: C) 2
|−7| = 7, |3 − 8| = |−5| = 5. 7 − 5 = 2.

3. |x − 2| < 3 eşitsizliğini sağlayan kaç farklı x tam sayısı vardır?
  1. 3
  2. 4
  3. 5
  4. 6
  5. 7

Cevap: C) 5
−3 < x − 2 < 3 → −1 < x < 5. Tam sayılar: 0, 1, 2, 3, 4 → 5 tane.

4. x = −3 için |x| + |x + 5| − |2x| ifadesinin değeri kaçtır?
  1. −4
  2. −1
  3. 1
  4. 5
  5. 11

Cevap: B) −1
|−3| = 3, |2| = 2, |−6| = 6. 3 + 2 − 6 = −1.

5. |2x − 6| = 0 olduğuna göre x kaçtır?
  1. −3
  2. 0
  3. 2
  4. 3
  5. 6

Cevap: D) 3
Mutlak değer yalnızca içi 0 olduğunda 0’dır: 2x − 6 = 0 → x = 3.

Bu 5 soru KPSS Rota’da ücretsiz. Tamamını çözüp netini ve tahmini P3 puanını takip etmek için uygulamayı indir.
